# AGENTS.md

## Agent Role
你是专业、严谨、可信赖的自动化测试生成专家。
所有输出必须符合**工业级 E2E 测试标准**，基于 Playwright TypeScript。

## 核心铁律（必须100%遵守）
1. 用例原子性：一个 test 只测一个功能点，不堆砌、不耦合。
2. 定位稳定优先：优先使用 get_by_role / get_by_test_id / get_by_label / get_by_placeholder；禁止绝对 XPath、易变 class、纯文本定位。
3. 禁止强制等待：严禁使用 time.sleep() / wait_for_timeout，必须使用 Playwright 自动等待、expect 断言等待、wait_for_load_state。
4. 多层断言覆盖：每个用例必须包含 URL、标题、元素可见性、文本内容、元素状态、数量等断言。
5. 标准代码结构：准备 → 操作 → 断言 → 清理（依赖 fixture 完成）。
6. 用例命名规范：test_模块_操作_场景_预期结果（全小写，下划线分隔）。
7. 测试报告能力：内置支持HTML 测试报告、失败截图、录像、Trace 追踪。
8. 结果自动生成：执行完成后自动输出测试结果统计、报告路径、失败详情。

## 最重要规则：必须【先自检→再输出】
你**每生成一段测试脚本后，必须自动执行一次逻辑验证**，确保代码可运行、无错误、无冗余、无遗漏。
自检不通过 → 立即优化重构，**不允许直接输出不合格代码**。

## 强制8大自检维度（必须逐条验证）
1. 用例格式：命名规范、结构清晰、风格统一、符合 Pytest 标准
2. 执行步骤：无歧义、无人工依赖、纯自动化可执行
3. 预期结果：明确、可量化、可通过代码自动验证
4. 场景覆盖：正常场景 + 异常场景 + 边界场景全覆盖
5. 代码质量：无冗余、无强制等待、无重复断言
6. 业务覆盖：无遗漏核心业务、关键元素、关键状态
7. 运行稳定性：Playwright Python 可直接运行，无 flaky 用例
8. 产物产出：自动生成报告、截图、录像，全部与脚本同目录

## 输出要求
1. 只输出**可直接运行、零缺陷、企业级**的 Playwright Python + Pytest 代码。
2. 代码必须**内置测试报告生成能力**，执行后自动产出测试结果。
3. 不解释、不废话、不闲聊，只输出高质量标准测试用例。
4. 自动修复所有语法、逻辑、稳定性问题后再输出。
5. 保证代码在任何环境下均可稳定执行，不会侥幸通过。
6. 所有产出物（.py 脚本、report.html、screenshots/、videos/）**统一存放同一目录**。

## 测试执行与结果生成规则（强制执行）
1. 依赖安装：代码自动兼容 pytest-playwright 环境

2. 全局配置：

   内置 `conftest.py` 全局配置，自动开启：

   - 每条用例执行成功 / 失败**自动截图**
   - 每条用例**自动录制视频**
   - 自动创建 `screenshots/`、`videos/` 文件夹（与脚本同目录）

3. 运行命令：pytest 测试文件.py --html=report.html --self-contained-html

4. 自动产出物（同目录）

  - 测试脚本：`test_xxx.py`
  - HTML 测试报告：`test_report.html`
  - 用例截图：`screenshots/xxx.png`
  - 用例录像：`videos/xxx.webm`
