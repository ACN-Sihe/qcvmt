```markdown
# N4 系统集成需求
## 1. 集成概述
| 项目 | 说明 |
|------|
| 目标系统 | N4 |
| 集成方式 | 数据库直连 |
| 数据库类型 | Oracle |
| 接口类型 | 无 API，仅数据库访问 |
## 2. 集成约束
- N4 系统不提供 REST API 或其他服务接口
- 仅支持通过 Oracle 数据库直连方式获取数据
## 3. 风险与应对
| 风险 | 影响 | 应对措施 |
|------|----------|
| 表结构耦合 | N4 升级可能导致字段变更，影响数据读取 | 要求 N4 方提供专用视图，隔离业务表变更 |
| 性能影响 | 查询可能影响 N4 生产库性能 | 限制并发连接数，避免高峰期查询 |
| 数据安全 | 直连存在误写风险 | 仅授予 SELECT 只读权限 |
| 事务一致性 | 跨系统事务难以保证 | 采用最终一致性方案，避免分布式事务 |
## 4. 技术要求
- 使用只读数据库账号连接 N4 Oracle
- 通过连接池管控并发连接数
- 优先读取 N4 方提供的视图，而非直连业务表
- 敏感数据需脱敏处理
## 5. 待确认事项
- [ ] 需要从 N4 读取哪些具体数据/表
- [ ] N4 方是否可提供专用视图
- [ ] 数据同步频率要求（实时 / 定时）
- [ ] 数据量级评估
```
